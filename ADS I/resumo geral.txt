na manipulação de caracteres podem ser usados os caracteres "*" e "?" para exemplificar o seguinte:
* representa vários caracteres

ls *.txt
e ele vai citar todos os arquivos que terminem em .txt (lembrando que no esse .txt é so estetico pq ele nao significa extensão)

? representa somente um caractere
exemplo

temos os seguintes arquivos:
a1, a2, a5, a9 e a21

ls a?
e ele mostra o seguinte:

a2
a5
a9

umask - serve para definir as permissões padrão de novos arquivos e diretórios criados no sistema (normalmente ele vem com o 0022)
chmod - altera permissão de arquivo
chown - troca a posse do arquivo (user, group, other)

usamos a regra do octal para definir o grupo de permissões.

R = Read (ler)
W = Write (escrever)
X = Execute (executar)

0 - "- - -"
1 - "- - x"
2 - "- w -"
3 - "- w x"
4 - "r - -"
5 - "r - x"
6 - "r w -"
7 - "r w x"

O padrão do linux é vir 644 

então no arquivo ficaria

- rw- r-- r--
0  6   4   4

0/user/group/other -> nessa ordem

Engenharia de software

Diagrama de caso de uso:

Usado para definir o que cada ator no sistema poderá realizar seguindo um fluxo principal ou um fluxo alternativo, se atentando as possibilidades de erros ou de caminhos diferentes para alcançar o objetivo da função exemplificada.
extend serve para executar uma função extra/opcional no fluxo dependendo da condição ou das permissões do determinado autor (user stories).
include serve pra usar um outro caso de uso como parte do processo para executar a função.
Está sendo discutido e trabalhado UML (padrão de diagramar funções do app a ser desenvolvido, a fim de padronizar a criação de um software por meio de um fluxo principal tendo tanto funções que seguem o fluxo principal e entregam diferentes respostas de acordo com a função especificada)

Diagrama de classe:

Objeto = classe (são a mesma coisa nesse conceito de diagrama de classe)

Definido o objeto ele terá as suas caracteristicas (atributo), especificações (tipo), nome e funcões (Metodos), podendo estar ligado a outros objetos para definir sua função no programa.

Um exemplo pode ser o objeto "pessoa";

Pessoa
Caracteristicas: nome, cpf, telefone, endereço, idade
tipo: caractere (nome), cpf (caractere ou inteiro[usa caratere vai por mim]), telefone (mesmo caso do cpf), endereço (caractere), idade (inteiro)
Métodos: cadastrar usuário, excluir usuário, gerar senha, salvar uma resposta

essa uml é diretamente orientada a objetos e é complementar ao projeto para continuidade do mesmo, então grande parte dos projetos usam mais de um tipo de diagrama.
vale ressaltar que ela usa bastante pra backend pois planeja filtros para banco de dados, ficando mais fácil de manusear os dados posteriormente.

vetor - define um determinado numero de variáveis dentro da mesma variável.
Em vez de criar várias variáveis:

nota1, nota2, nota3

você cria:

notas[1..3]

Um vetor funciona como uma “lista organizada”.

Cada posição possui um índice.
---------------------------------------------------------
algoritmo "vetor"

var
   numeros : vetor[1..5] de inteiro

inicio

   numeros[1] <- 10
   numeros[2] <- 20
   numeros[3] <- 30

   escreval(numeros[1])
   escreval(numeros[2])
   escreval(numeros[3])

“pegue o valor da posição 1”

caso - funciona como uma condição que executa um comando com base nas opções descritas

um exemplo:

algoritmo "caso"

var
   opcao : inteiro

inicio

   escreva("Digite uma opcao: ")
   leia(opcao)

   caso opcao seja

      1:
         escreval("Voce escolheu jogar")

      2:
         escreval("Voce escolheu configuracoes")

      3:
         escreval("Voce escolheu sair")

   outrocaso
      escreval("Opcao invalida")

   fimcaso

fimalgoritmo


um algoritmo que ela passou é um bom exemplo:


Algoritmo "Adquirir apólice(Caso)"

// Descrição   : Verificar codigo do seguro (caso)

// Uma companhia de seguros tem três categorias de seguros
// baseadas na idade e ocupação do segurado. Somente pessoas
// com pelo menos 18 anos e não mais de 70 anos podem adquirir
// apólices de seguros. Quanto às classes de ocupações foram
// definidos três grupos de risco. A tabela a seguir fornece as
// categorias em função da faixa de idade e do grupo de risco:


//  Idade                   Grupo de Risco
//                 Baixo         Médio     Alto
// 18 a 24          7             8         9
// 25 a 40          4             5         6
// 41 a 70          1             2         3

// Faça um programa que receba a idade e o grupo de risco
//( B, M ou A) e determine e mostre na tela o código do seguro.

var
   idade: inteiro
   risco: caractere
   codigo: inteiro

inicio
   escreva("Digite a idade: ")
   leia(idade)

   // Validação da idade
   se (idade < 18) ou (idade > 70) entao
      escreva("Não pode adquirir seguro")

   senao
      escreva("Digite o grupo de risco (B, M ou A): ")
      leia(risco)

      // Faixa 18 a 24
      se (idade <= 24) entao
         escolha risco
            caso "B"
               codigo <- 7
            caso "M"
               codigo <- 8
            caso "A"
               codigo <- 9
            outrocaso
               escreva("Grupo de risco inválido")
         fimescolha

      senao
         // Faixa 25 a 40
         se (idade <= 40) entao
            escolha risco
               caso "B"
                  codigo <- 4
               caso "M"
                  codigo <- 5
               caso "A"
                  codigo <- 6
               outrocaso
                  escreva("Grupo de risco inválido")
            fimescolha

         senao
            // Faixa 41 a 70
            escolha risco
               caso "B"
                  codigo <- 1
               caso "M"
                  codigo <- 2
               caso "A"
                  codigo <- 3
               outrocaso
                  escreva("Grupo de risco inválido")
            fimescolha
         fimse
      fimse

      // Exibe só se for válido
      se ( (risco = "B") ou (risco = "M") ou (risco = "A") ) entao
         escreva("Código do seguro: ", codigo)
      fimse

   fimse

copia - serve pra copiar parte do texto de uma linha a partir de uma posição.

algoritmo "copia"

var
   nome : caractere

inicio

   nome <- "Gustavo"

G u s t a v o
